Basic steps for adding

  • 1. PickADisk Startup Window
  • 2. Select strorage device
  • 3. Select slot number
  • 4. Select disc
  • 5. Enter a title for the disc
  • 6. Select the type of disc
  • 7. Set the scanning level
  • 8. Add the disc to the device
1
PickADisk Startup Window
Click either add button to begin the process.
2
Select strorage device
Select a storage device to be used.
3
Select slot number
The next available slot number will be entered automatically.

If you desire a specific slot, you may enter the number in one of two ways.
Type in the slot number using the keyboard.
Click on the wheel and drag to select the number.
If the slot number already contains a disc you will see the title in the title box.
If you click on the arrow the device will go to the numbered slot and eject the disc.
4
Select disc
Select the disc to be added. 
Use the popup menu to select the drive to be used, the title box will be filled in automatically.
5
Enter a title for the disc
Enter the title manually if you don't like the automatic generated name.
6
Select the type of disc
The type of disc is detected automatically.
If you prefer a different type, use the popup menu to select the type of disc.
7
Set the scanning level
Set the desired scanning level. This will control how much detail of the content of the disc will be included in the index.
The far left setting will only scan the top level content of the disc.
The far right setting will index the entire disc.

The settings default value can be controlled for different types of discs in the preferences panel.
8
Add the disc to the device
Click on the Add button to add the disc.

Repeat the steps to keep adding discs to the device.
